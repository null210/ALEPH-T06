# 잠긴 앱 5일 사용 기록

흐름: **로그인 → 오늘 할 일·실행 기록 → "오늘 기록" 화면에 오늘 값 저장 → 로그아웃**

5일 기록의 원본은 **내 계정 안**(앱 위쪽 메뉴 "오늘 기록", `#/diary`)에 있습니다. 이 문서는 마지막에 그 화면의 값을 옮겨 적는 곳입니다.

## 앱이 지키는 것 (설정이 아니라 코드로 막혀 있음)

- 질문·지표·단위·계산 규칙·처음 계획 규칙은 **1일차 전에 한 번만** 정합니다. 다시 보내면 409로 거절합니다.
- 날짜는 서버가 정한 **오늘(Asia/Seoul)**로만 저장됩니다. 지난 날짜나 앞 날짜로는 적을 수 없습니다. 그래서 5일은 서로 다른 실제 날짜가 됩니다.
- 기록이 정확히 2일일 때만 계획 규칙을 **한 번** 바꿀 수 있습니다. 바꾸지 않으면 3일차를 저장할 수 없습니다.
  규칙 변경 기록에는 바꾼 시각, 바꾸기 전·뒤 규칙, 이유가 남고, 1일차·2일차 기록을 가리킵니다.
- 전후 비교는 같은 지표·같은 단위·같은 계산 규칙의 평균으로 합니다. 화면에 "합계 = 45 + 60 = 105" 같은 식을 그대로 보여 줘서 손으로 더한 값과 맞춰 볼 수 있습니다.

## 처리 규칙 (화면 "기록 처리 규칙"과 같은 문장, [server/diary.js](../server/diary.js)의 `FIXED_RULES`)

| | 규칙 |
|---|---|
| 값이 빠졌을 때 | 값을 비워 저장한 날은 "빠짐"으로 둔다. 0으로 치지 않고 합계·평균에서 뺀다. 평균은 값이 있는 날 수로 나눈다. 아예 기록하지 않은 날은 일차로 세지 않는다. |
| 같은 날 두 번 저장할 때 | 그날 값을 새 값으로 바꾼다. 한 날짜에는 값이 하나만 남고, 고친 시각이 함께 보인다. 지난 날짜는 고칠 수 없다. |
| 값이 튈 때 | 튀는 값도 빼지 않고 그대로 계산한다. 같은 단계 다른 날 평균의 2배보다 크거나 절반보다 작으면 "튐" 표시만 붙인다. |
| 반올림 | 평균은 소수 둘째 자리에서 반올림해 첫째 자리까지 보인다(0.05 → 0.1, 반올림은 0에서 먼 쪽). 합계는 입력값 그대로 더한다. |
| 주 시작 요일 | 월요일. 각 기록 옆에 그 주의 월요일 날짜를 붙인다. |
